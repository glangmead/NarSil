# The touch panel's slot tabs.  Edit it freely; the Menu's "Reset Panel
# Slots" brings this file back.
#
# tab:Name  starts one of the tabs Act, Items, Info and Mine.
# row:...   fills that tab's next row of cells, top row first; a tab
#           holds 4 rows of 7.
#
# A cell is one of
#   [Description]  a command, named as the command menu names
#                  it; its key is looked up for whichever
#                  keyset is in force when it is pressed.
#   "action"       a keymap's action, written exactly as a
#                  pref file's keymap-act: line writes one:
#                  "za." is three keypresses, "[Escape]" is
#                  the escape key, "{^}f" is control-F.
#   -              nothing.
# Any of them may end in =Face to change the word shown on it.
#
# Order.  The grid sits by the right thumb, with Escape and Enter in
# the bottom corner, so the bottom row is the easiest to reach and
# its right end the easiest of all; the top row is the hardest.  Each
# tab below puts its most used commands there, following the Android
# port's ribbon order (its "most used commands", by its author)
# adjusted for what the compass rose already covers: walking, staying
# (its centre), running (Shift) and altering (Ctrl).  The top row is
# left empty on every tab; it is where the fast keys will appear when
# a prompt is asking for something.
#
# NarSil's own commands take the places Angband gives magic.  Stealth
# mode is toggled every few turns, so it sits on Act's bottom row
# where Angband casts spells; songs change less often and sit a row
# up.  Smithing, the horn and the two quivers take the wand, rod and
# scroll slots on Items.
#
# Mine is yours: macros, as keymap actions.  It starts with the three
# answers to the rest prompt, so that each is one tap: '&' rests as
# needed, '*' until HP and SP are full, '!' until either is.  Rest is
# 'Z' in NarSil's own keyset, which is the one these assume; under
# the Angband keyset it is 'R' and these three want editing.
